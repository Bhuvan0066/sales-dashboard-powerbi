# 📊 Sales Performance Dashboard

Interactive dashboard built using Power BI to analyze sales data across regions, categories, and time.

## 🚀 Features

* KPI Cards: Sales, Profit, Orders, Quantity
* Sales by Region (Bar Chart)
* Sales by Category (Donut Chart)
* Monthly Sales Trend (Line Chart)
* Filters: Region & Category

## 📌 Insights

* South region has highest sales
* Technology category leads revenue
* Sales trends vary across months

## 🛠 Tools

* Power BI
* CSV Dataset

* Sales_Data.csv
